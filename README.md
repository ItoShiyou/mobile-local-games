# mobile-local-games

スマートフォン向けのローカル（オフライン）パズルゲーム集です。

| アプリ | 内容 |
| --- | --- |
| [apps/tsumiage_demae](apps/tsumiage_demae) | つみあげ出前 — 料理を頭に積んで、順番どおりに届けるパズル（Flutter） |
| [apps/fusuma_watari](apps/fusuma_watari) | ふすま渡り — ふすまを押して、客間まで出前を届けるパズル（Flutter） |
| [apps/dashi_mawashi](apps/dashi_mawashi) | だし回し — 竹の樋を回して、だしをお椀へ届けるパズル（Flutter） |
| [apps/demae_neko_mocks](apps/demae_neko_mocks) | 出前ねこ 次の一皿 — 同じねこが主人公の次回作の案（ブラウザで遊べるモック） |
