# 出前ねこ 次の一皿（モック）

「つみあげ出前」のねこを主人公にした、次のゲームの案を5つ、ブラウザで遊べるモックにしたものです。
どれを本実装（Flutter）に進めるかを決めるための試作で、各案4問ずつ入っています。

| 案 | 名前 | ひとことで |
| --- | --- | --- |
| 1 | すべって出前 | 雨の商店街。すべり出したら、何かにぶつかるまで止まらない。ぶつかったお客さんに配達 |
| 2 | おかもち詰め | 出前箱に料理をぴったり詰める。熱いものと冷たいものは隣に置けず、汁物は下の段 |
| 3 | ひとふで出前 | 路地を一度ずつ全部通り、番号の家に順番どおり寄る一筆書き |
| 4 | 皿そろえ屋台 | 屋台の台に積まれた皿を、種類ごとにそろえる |
| 5 | 注文あてっこ | 常連さんの話から、だれが何を頼んだかを当てる推理 |

## 作り方

```sh
node tool/gen.js     # 問題を作って src/levels.js に書き出す（全問の検査つき）
node tool/verify.js  # 全問が解けること、案2・3・5は答えが1通りなことを確かめる
node tool/build.js   # dist/index.html（1ファイル）にまとめる
```

- `src/logic.js` … 5案のルールと解く処理（描画なし。node から検査に使う）
- `src/art.js` … ねこ・お客さん・料理の絵（Canvas）
- `src/games.js` … 5案の画面と操作
- `src/shell.js`, `src/page.html` … 一覧、遊ぶ画面、クリア時のレシート
