# 出前ねこ 次の一皿（モック）

「つみあげ出前」のねこを主人公にした、次のゲームの案をブラウザで遊べるモックにしたものです。
どれを本実装（Flutter）に進めるかを決めるための試作です。

2回目の案出しでは、1回目から「おかもち詰め」だけを残し、**しかけを足していけるか**を軸に4案を作り直しました。
どの案も4問で、2問目からしかけが1つずつ増えます（1回目の5案は git の履歴にあります）。

| 案 | 名前 | 遊び方 | モックに入れたしかけ | これから足せるしかけ |
| --- | --- | --- | --- | --- |
| 残した案 | おかもち詰め | 出前箱に料理をぴったり詰める | 熱い／冷たいは隣に置けない、汁物は下段 | 割れもの、二段重ね、配達順、大盛り |
| 新案1 | おでん仕込み | 具を押して鍋へ。鍋は札の順番でしか受けつけない | 鍋ふたつ、つるつる床 | 重い具（2マス）、だしの流れ、火加減 |
| 新案2 | あかり届け | びょうぶを押して、行灯の光を提灯へ | 提灯ふたつ、赤い和紙（赤い光）、すだれ（半分通す） | 回転台、動く人影 |
| 新案3 | ふすま渡り | ふすまを敷居にそって押し、客間まで配達 | 連動ふすま、女将さんの鍵 | 回り障子、寝ている客、階段 |
| 新案4 | だし回し | 竹の樋を回して、だしをお椀へ | 合わせだし（混ざる）、鉄の樋、交差 | 栓、温度 |

## 作り方

```sh
node tool/gen.js [案...]  # 問題を作って src/levels.js へ（案を省くと、未作成の案だけ）
node tool/verify.js       # 全問が解けること、目標手数が最短であること、おかもち詰めは答えが1通りなこと
node tool/build.js        # dist/index.html（1ファイル）にまとめる
```

- `src/logic.js` … ルールと解く処理（描画なし。node から検査に使う）
- `src/art.js` … ねこ・お客さん・料理の絵（Canvas）
- `src/games.js` … 各案の画面と操作
- `src/shell.js`, `src/page.html` … 一覧、遊ぶ画面、クリア時のレシート
