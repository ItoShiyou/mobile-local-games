# アートディレクション：「AIっぽさ」を抜く

つみあげ出前の絵は、画像を使わずにすべて Canvas のコードで描いています。コードで描いた絵は、放っておくと「どこかで見た生成画像」の顔になりがちです。この文書では、参考にした資料と、そこから決めた描き方のルールをまとめます。ふすま渡り・だし回しへ移植するときの手順も最後に書きます。

## 1. 参考資料と、そこから取り出したこと

### 何が「AIっぽい／量産ベクター」に見えるのか
- **AI生成画像の見分け方（各種ガイド）**
  - https://stable-diffusion-book.vercel.app/en/paint/identify
  - https://imagera.ai/blog/ai-art-detector-how-to-tell-2026
  - https://citrusnotes.pagecord.com/identifying-a-i-generated-images-some-advice
  - 取り出したこと：
    - 「なめらかなグラデーション、きれいすぎる線、理想化された形」は、それだけでは証拠になりません。ただ、**全部が同時にそろうと量産品に見えます**。
    - 見分けの手がかりは、細部の密度のむら、同じ微細パターンの繰り返し、意味のない偽文字です。
    - なので、**偽の文字を描かないこと**。文字らしい形を並べると、逆に「AIの崩れた文字」に見えます。
- **Corporate Memphis への批判**
  - https://notes.jim-nielsen.com/n/2021-05-28-1225/
  - https://eyeondesign.aiga.org/what-the-think-pieces-about-corporate-memphis-tell-us-about-the-state-of-illustration/
  - 取り出したこと：
    - 平たい単色、同じ角丸、均一な線、どこにでも同じ部品という組み合わせが、「誰が描いても同じ」顔をつくります。
    - 素材サイトで誰でも組み立てられる形は、無個性に見えます。

### 手で描いた／刷った絵に見せる技法
- **線の強弱（インキング）**
  - https://www.tomrichmond.com/inking-tutorial-part-ii/22/08/2006/
  - https://cursa.app/en/page/digital-drawing-on-a-tablet-clean-line-art-techniques-line-weight-tapers-and-corners
  - 取り出したこと：
    - **光の当たる側は細く、影側は太く**します。
    - 太さは細部・輪郭・重なりの3段階に分けます。
    - 均一な線はアニメ的な選択肢ではあります。ただ、全部が均一だと機械的に見えます。
- **リソグラフの版ずれ**
  - https://sites.saic.edu/servicebureau/wp-content/uploads/sites/20/2025/03/EverythingRiso_2024.pdf
  - https://oxfordgreenprint.com/?p=223
  - https://campus.collegeforcreativestudies.edu/imaging-center/?p=3493
  - 取り出したこと：
    - 版ずれは「必ず起こる」ものとして設計に組み込みます。
    - 色数を2〜3色に絞り、重なりで3色目を作ります。
    - 少しのずれは立体感として働きます。
- **木版画（浮世絵）の主版・ぼかし**
  - https://www.roningallery.com/how-to-make-a-woodblock-print
  - https://projects.mcah.columbia.edu/jaanus/node/5065 （bokashi）
  - https://projects.mcah.columbia.edu/jaanus/node/3720 （ita bokashi）
  - 取り出したこと：
    - 輪郭は主版（墨線）、色は別の版のベタで刷ります。
    - グラデーションは、空や水など「ここぞ」の場所だけに、段や帯として使います。
    - 見当（kento）がわずかにずれる刷り味が出ます。
- **木版の摺り（バレン・木目・水性顔料）**
  - https://explore.beatymuseum.ubc.ca/peatland/process/mokuhanga/
  - https://makingamark.blogspot.com/2025/02/about-mokuhanga-japanese-woodblock-printing.html
  - 取り出したこと：
    - 顔料の量や圧のむらで、ベタは**透け・斑点・むら**を持ちます。
    - **白は紙の白**です。光沢を白で描き足しません。
    - バレンの跡や木目がうっすら残ります。
- **ジェネラティブアートでの「不完全さ」**
  - https://www.tylerxhobbs.com/process
  - https://www.euronews.com/2023/03/23/how-generative-artist-tyler-hobbs-blurs-boundaries-between-machine-and-hand-made-art
  - 取り出したこと：
    - アルゴリズムに意図して不完全さを入れます。
    - 手の動きを入力に使います。不完全さは失敗ではなく「指紋」として扱います。
- **のれん**
  - https://voyapon.com/noren/
  - https://collections.vam.ac.uk/item/O12809
  - 取り出したこと：
    - 藍地に**白抜き（染め抜き）**で屋号や紋を入れます。
    - 縫い返した裾と、染めむらがあります。
    - 紋は手で描かれていて、完全な正円ではありません。
- **昭和レトロの看板・ホーロー看板**
  - https://online.bunka.go.jp/db/heritages/detail/564565
  - https://www.fun-japan.jp/jp/articles/14254
  - 取り出したこと：
    - 色数は少なく、黒文字か白抜き文字を使います。
    - 赤は白・黒・黄と組ませて目立たせます。
    - 店先は年月で貼り足され、間隔も傾きも揃っていません。
- **インディーゲームの手描き表現**
  - https://www.creativebloq.com/3d/video-game-design/mio-memories-in-orbits-stunning-hand-drawn-art-direction-explained-by-its-creators
  - https://gamedev.net/news/5460-73-easy-art-styles-for-game-devs/
  - 取り出したこと：
    - 色を絞り、形を単純にし、あえて手の跡を残すと、コストを抑えつつ個性が出ます。
    - そのためには、アートバイブル（この文書）でルールを固定します。

## 2. 診断：変更前の何がAIっぽかったか

| 要素 | 症状 | なぜAIっぽいか |
|---|---|---|
| すべての輪郭（`Art.inked`） | 全部同じ太さの墨線で、色はぴったり線の内側 | ベクター素材そのもの。手でも版でも、こうはならない |
| 料理のハイライト | トマト・団子・ぶどうに白い楕円の「テカリ」 | ストックイラストの定番の光沢表現 |
| 影・光 | `MaskFilter.blur` の落ち影、放射グラデのビネット・灯り、なめらかな空グラデ | 「ぼかしとグロー頼み」は生成画像の典型 |
| 窓からの日差し | ぼかした斜めの帯と全面グラデ | 同上。光源の形がない |
| 短冊・張り紙 | 等間隔・同じ幅で、点線（‐‐‐）の偽文字 | 均一な繰り返しと、意味のないプレースホルダ |
| 床（タイル・石畳） | 完全な市松模様と、同じ角丸の石の格子 | 「同じ角丸がどこにでも」 |
| 伝票・椅子・机 | どれも同じ角丸長方形 | 同上 |
| 猫 | 左右対称の耳・ひげ・頬（半透明の円） | 完全対称は機械的に見える |
| のれんの紋 | 完全な正円の線 | 染め抜きの手の跡がない |
| タイトル画面 | のれん・看板・扉がすべて中央揃え。空はグラデ、石畳は同じ大きさ | 中央構図＋均一な繰り返し |
| ボタン | 上辺の白い光沢線、ぼかしたグロー | Webの汎用ボタンの顔 |
| 色 | 紙・床・壁がすべて淡いベージュで、明度差が小さい | 「パステルベージュ一色」 |

## 3. ルール（実装済み）

1. **刷った線にする**（`Art.inked`, `kInkWeight`, `kRegistration`）
   - 1回の塗りを3回の描画に分けます。
     1. 右下にずらした墨のベタ。影側が太くなります。
     2. 左上に約0.7線幅ずらした色版。版ずれになります。
     3. 細い主版の線。
   - パスの計算はしないので、毎フレーム描くスプライトでも軽いままです。
2. **光沢を白で描かない**（`Art.nick`）
   - ハイライトは「刷り残した紙の白」の短い弧にします。
   - 全部の粒には入れず、ところどころにだけ入れます。
3. **ぼかしを使わない**
   - 影は、ずらした硬いベタにします。
   - 灯りは2段のベタにし、`BlendMode.overlay` で暖色を保ちます（`Art.lightPool`）。
   - 空は帯状のぼかしにします（`_bandedSky`。ita-bokashi のように段で刷り、境目が少し揺れます）。
   - 例外は、起動時に1回だけ作るテクスチャ（`PrintGrain`）の中だけです。
4. **ベタに摺りむらを乗せる**（`PrintGrain`）
   - バレン跡、斑点、刷り残しを持つタイル画像を一度だけ作り、ベタの上に重ねます。
   - これまでの紙の繊維（`PaperGrain`）とは別の質感です。
5. **偽文字を描かない**（`Art.scribble`）
   - 遠目の筆書き（つながった運筆、語の切れ目、筆圧の変化）として描きます。
   - 字の形は作らないので、崩れた文字には見えません。
6. **繰り返しを崩す**
   - 短冊の幅・間隔・傾き。
   - 石畳の石の長さ。
   - タイルの焼きむら、混じった別色、欠け。
   - 目地は手描きの線にします。
   - 器も、料理ごとに違う器（染付・益子の角皿・長皿・水玉の小鉢）にします。
7. **同じ角丸を使い回さない**
   - 伝票は四角い上辺とちぎれた下辺にし、朱の罫を入れます。
   - 椅子は曲木の背、机は木目と節のある角材です。
8. **対称を崩す**
   - 猫の耳は左右で高さと開きが違います。
   - 頬の毛のはねは左右で位置が違います。
   - ひげは左右で角度と長さが違います。
   - 三毛の模様は不定形です。
   - タイトルの扉は中央から右へずらしました。
9. **色を絞り、明度差をつける**
   - 墨 `#33251E`、藍 `#2C4766` 系、朱 `#C9432C` 系、生成り `#F1E4C8`、からし（灯り）を主役にします。
   - まちの食堂は、間仕切りの天板を濃い木色（`#A9774B`）にして、床との明度差を出しました。
10. **猫はデザインと比率を変えない**
    - 変えたのは線質（版ずれ・影側の太さ）、頬（ベタ＋斜線）、ひげ、耳の左右差、三毛模様の形、尻尾の筆致だけです。

## 4. 制約の確認
- プレイ中に文字は出しません。短冊の「筆書き」は字の形を持たない装飾です。
- 外部画像は使いません。テクスチャはすべて実行時にコードで生成します。
- フォントは変更していません。
- 夜（evening）、モーション軽減、文字倍率1.3倍の制限は、既存のロジックのままです。テストで確認しています。
- 性能：盤面の固定部分は従来どおり `SceneLayers` に1回だけ記録します。路面の矢印・石畳・灯りの揺れた縁など、パス計算が必要なものはそこにだけ置きます。毎フレームの差分は、次の3つだけです。
  - `inked` の描画が1回増えたこと
  - `PrintGrain` の画像シェーダー矩形が1枚増えたこと
  - 灯りの円が2つになったこと（ぼかしをやめたので、むしろ軽くなります）

## 5. ふすま渡り・だし回しへの移植手順
両アプリは同じ `art.dart` / `paper.dart` / `board_painter.dart` の系統です。次の順に入れると安全です。

1. `paper.dart` に `PrintGrain` クラスを丸ごとコピーします。
   - `PaperBackground` の放射グラデ（ビネット）を消して、`PrintGrain.paint` に置き換えます。
   - `PaperSlip` の影をぼかしなしのずらした影にします。
2. `art.dart` について：
   - `kInk`・`kInkWeight`・`kRegistration`・`Art.inked`（3回描き）・`Art.shadow`（硬いベタ）・`Art.nick`・`Art.scribble`・`Art.lightPool` をコピーします。
   - `art.dart` から `paper.dart` を import します（`Wob` を使うため）。
   - `inked` に半透明の色を渡している箇所は、下の墨が透けるので、不透明色に `Color.lerp` で置き換えます。
3. 料理・小物の白い楕円ハイライトを `Art.nick` に置き換え、全部ではなく一部にだけ入れます。
4. `board_painter.dart`（各アプリの盤面ペインタ）では、次をすべて置き換えます。
   - `MaskFilter.blur`
   - `RadialGradient`
   - 影用の `LinearGradient`
   - 置き換え先：
     - 落ち影 → ずらしたベタ1枚
     - 壁際の影 → 2段のベタ（左と上の壁だけ。光は左上から）
     - 夜の灯り → `Art.lightPool(..., rough: true)`（キャッシュ層の中だけ）
     - キャラの灯り → `Art.lightPool`（rough なし）
     - 最後の重ね → `PaperGrain .4` ＋ `PrintGrain .85`
5. 背景（`backdrop.dart` 相当）について：
   - 空のグラデは `_bandedSky` にします。
   - 短冊や張り紙の点線は `Art.scribble` にし、間隔・幅・傾きを `_h` でばらつかせます。
6. UI について：
   - `WoodButton` の白い光沢線とぼかしグローをやめて、2段の硬い縁取りにします。
   - お盆パッドの光沢弧を金の細線＋`PrintGrain` にします。
   - のれんの紋は、筆で描いた輪（始点と終点が重なる）＋裾の濃い帯にします。
7. アイコン（`tool/make_icons.js`）について：
   - `draw` 関数の中だけを差し替えます。
   - 背景はベタ、`inked` ヘルパーで線の強弱と版ずれをつけ、光沢をやめ、最後に摺りむらを足します。
   - 書き出し部分（`jobs` や iOS の不透明PNG化など）には触れません。
8. 各アプリ固有のキャラ（ふすま渡り・だし回しの猫も同じ猫）は、`Art.courier` の差分（耳の左右差、不定形の三毛、頬、ひげ、尻尾）をそのまま当てられます。

## 6. 試してやめたこと
- **字の形を組み合わせた偽文字**（十・二・かぎの組み合わせ）：遠目でもカタカナの崩れに見えて、生成画像の「意味のない文字」そのものになりました。運筆だけの筆書きに変えました。
- **規則的なジグザグの筆書き**：バネのような模様に見えたので、縦画とはねを混ぜました。
- **3段の灯り（同心円）**：的（まと）のように見えました。2段にして、芯を下へずらしました。
- **灯りを `screen` 合成**：夜の色の上では灰色のもやになりました。`overlay` に変えて暖色を残しました。
- **版ずれを線幅の0.35倍**：画面では見えませんでした。0.7倍にしました。アイコンは大きく描くので、ずれが目立ちすぎます。そこでアイコン側だけ0.5倍にしました。
- **斜めの日差しを強く**：床が縞模様になりました。透明度を下げ、窓の桟で2枚に割りました。
