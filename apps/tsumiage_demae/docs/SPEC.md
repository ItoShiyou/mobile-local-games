# つみあげ出前 — リリース版 仕様書

プロトタイプ「チルパズル工房 第2弾」の「つみあげ出前」を、Flutter でリリース水準に仕上げたものです。
見た目と操作の基本は「チルパズル工房 UI/UX現状仕様書」（以下、UI/UX仕様書）に合わせ、同書 11章で
「未実装・既知の課題」とされていた項目を埋めています。

## 1. ルール

| 要素 | 記号 | ふるまい |
| --- | --- | --- |
| 出前ねこ（自分） | `P` | 上下左右に1マスずつ動く |
| 料理 | `a`〜`d` | 上を通ると必ず拾い、頭の上に積む。上限（2〜3皿）を超えて載せられないときは、そのマスに入れない |
| お客さん | `A`〜`D` | 壁と同じく通れない。ぶつかると一番上の料理を渡す（注文と同じ料理のときだけ）。渡しても自分は動かない |
| 返却口 | `T` | ぶつかると一番上の料理を1皿引き取る。1回だけ |
| くるりトレイ | `s` | 乗ると頭の上の順番が上下逆になる（2皿以上のとき） |
| 一方通行 | `< > ^ v` | 矢印の向きに進むときだけ入れる。出るのは自由 |

全員に配ればクリア。余った料理が残っていても構いません。失敗状態はなく、詰んだときは画面上でお知らせします。

料理は色だけでなく形も違います（トマト＝丸と葉、抹茶だんご＝串に3玉、卵焼き＝縞の入った四角、ぶどう＝房）。
UI/UX仕様書 KI-08（色だけで区別している）への対応です。

## 2. ステージ構成（全46面）

| 章 | 名前 | 面数 | 内容 |
| --- | --- | --- | --- |
| 1 | はじめての出前 | 10 | 基本ルール。拾う順番と積み方 |
| 2 | 返却口 | 8 | 返却口 |
| 3 | くるりトレイ | 8 | くるりトレイ（3皿まで載る面あり） |
| 4 | 一方通行 | 8 | 一方通行 |
| 5 | 満員御礼 | 12 | 3つのしかけの組み合わせ |

- プロトタイプの14面はすべて収録し（`lib/game/levels.dart` で `(試作)` と注記）、残りは
  `tool/gen_levels.dart` で大量に自動生成した候補から、難しさの並びを見て選びました。
- `test/levels_test.dart` がすべての面について次を検証します。
  - 解けること、`par`（目標手数）が本当の最短手数であること
  - 床マスがすべて到達可能で、盤面が 8×8 以内に収まること
  - 盤面にあるしかけが、外すと最短手数が変わる（または解けなくなる）こと
  - しかけを初めて紹介する面は、そのしかけがないと解けないこと
- 面の ID（`b01` など）は保存データのキーなので、公開後は変更・再利用しません。

「商店街のねこの出前屋」を絵本の画材で描きます。画面の部品はすべてこの世界の中の物として作り、
汎用UI部品（Materialのアイコン・スイッチ・セグメントボタン・影付きカード）は使いません。

| 要素 | 表現 |

## 4. 画面

画面は「アプリの操作盤」ではなく、お店の中の物でできています。ボタンの並んだ帯やカードは作りません。

| 画面 | 内容 |
| --- | --- |
| タイトル（店構え） | 瓦屋根と大看板、格子窓、暖簾のかかった入口（くぐると「はじめる／つづきから」）、入口わきで待つねこ、立て看板（チョークの行がそのままメニュー）、窓の横に貼った判子の数、軒下の設定の木札 |
| ゲーム（店内） | 画面全体が舞台の壁。上は梁と暖簾（店名・面の名前）、梁から下がる木札（戻る・ルール・設定）、伝票差しに留めた注文伝票、壁に掛かった黒板（手数／目標と、運べる皿の数をチョークの皿で）。中央の部屋は外周の壁を床ぎわだけ細く描き、壁に溶け込ませる。下はカウンター：お盆の十字キー、横木から下がる縦書きの木札（戻す・進む・やり直す）とヒントの提灯 |
| お品書き | 店の壁に章ごとの暖簾と、縦書きの品書き札の列。札には番号・面の名前・判子。準備中の札は色の沈んだ木。次に遊ぶ札は灯りがともり、ねこがのぞく |
| 設定 | 帳場の机に置いた帳面の1ページ（綴じ穴と朱の罫線）。夜でも紙は生成りのまま |
| あそびかた | 机の上の絵本。各ページで小さなジオラマが動く |

壁には舞台ごとに、短冊の品書き・時計・暦（食堂・定食屋）、額とランプ（喫茶店）、遠くの屋根と板塀（路地裏）、夜空と提灯の列（夏祭り）が描かれる。

### 4-1. フィードバック

- プレイ中は文字を出さない。何が起きたかは盤面の動きで伝える（ぶつかるとねこが前のめりになる、
  注文違いのお客さんは首を振って注文札が揺れる、もう持てないときは皿の塔がぐらつく）。
  読み上げ（スクリーンリーダー）にだけ、同じ内容を短い文で知らせる。
- 注文違いで渡せなかったときは、ねこの頭の上でお客さんの欲しい皿が光り、その上に積んだ皿がカタカタ揺れる。
  「先に拾いすぎた」ことが、自分の目で分かるようにする。
- 詰んだことは先回りして知らせない。詰んだ状態でぶつかるか提灯（ヒント）を押したら、「戻す」の札が
  ときどき揺れて灯りをまとい、戻せば直ることをそっと示す。まだ詰んでいる間は揺れ続け、解ける状態まで戻ると止まる。
- ヒントは次に進むマスにねこの足あと、十字キーの該当する腕が灯りで光る。
- クリアすると盤面の下からレシートがせり上がり、判子（最大3つ）が押される。目標手数で3つ。
- 新しいしかけは、テープで貼られた「おしらせ」の張り紙で紹介する。

## 5. アニメーションと音

- 移動 140ms、拾う 240ms（皿が床から頭上へ弧を描いて飛ぶ）、渡す・返却 320ms（皿が頭上からお客さん／返却口へ）、
  反転 380〜460ms（皿の塔が半回転し、トレイも回る）、元に戻す 110ms。
- 待機中はねこが呼吸し、お客さんと吹き出しがゆっくり揺れる。配り終えたお客さんは笑顔になり、料理が卓に置かれる。
- 「アニメーションを減らす」または端末の視差効果を減らす設定がオンなら、すべて即座に切り替わる。
- 効果音（歩く、拾う、渡す、返却、反転、ぶつかる、クリア、戻す、ボタン）とBGMは `tool/make_audio.py` で合成した
  オリジナル。iOS ではマナースイッチに従い、他のアプリの音楽と混ざる。アプリがバックグラウンドに回るとBGMを止める。

## 6. ヒントと詰み

- 盤面の状態数は数百〜数千なので、1手ごとに幅優先探索で「まだ全員に配れるか」を調べる。結果は画面に
  書かず、上の「戻す」の札の合図とヒントにだけ使う（詰んでいるときに提灯を押すと、足あとの代わりに札が揺れる）。
- ヒントは現在の状態からの最短解の1手目を、盤面（目的のマスの枠と矢印）と十字キーの両方で示す。
  ヒントどおりに動いている間は次のヒントを続けて表示する。
