# ストア申告の回答メモ

アプリの実装（2026年9月時点）にもとづく回答です。広告・解析・通信を追加したら見直してください。

## 前提として確認したこと

- 通信：リリース版の Android アプリはインターネット権限を持ちません（Flutter はデバッグ版にだけ付与）。iOS も通信を行うコードはありません。
- 使用プラグイン：`shared_preferences`（端末内保存）、`audioplayers`（同梱の音声ファイルの再生）。どちらも権限を追加せず、外部送信もしません。
- 保存するもの：クリア状況・最少手数・最後に遊んだ面・設定。すべて端末内のみ。
- 広告・課金・アカウント・解析・クラッシュレポート：なし。

## App Store Connect

### App のプライバシー（App Privacy）

- 「このAppからデータを収集していますか？」→ **いいえ、このAppからデータを収集していません**
  - 端末内にだけ保存して外部に送らない情報は「収集」に当たりません。
- トラッキング：**なし**（App Tracking Transparency のダイアログも不要）

### プライバシーマニフェスト

- `shared_preferences` の iOS 実装と Flutter 本体が、それぞれ PrivacyInfo.xcprivacy（UserDefaults の利用理由 CA92.1 など）を同梱しています。
- アプリ自身のコードが「理由の申告が必要なAPI」を直接使うことはないため、追加の申告は不要の見込みです。提出時に Xcode の「Generate Privacy Report」で確認してください。

### 輸出コンプライアンス

- `ITSAppUsesNonExemptEncryption = false` を Info.plist に設定済み。暗号化は使っていません。

### 年齢制限指定

すべての項目「なし」→ **4+**
（暴力・性的表現・ホラー・ギャンブル・薬物・下品な言葉・ユーザー生成コンテンツ・無制限のWebアクセス、いずれもなし）

## Google Play Console

### データ セーフティ

- 「アプリは、必須のユーザーデータタイプのいずれかを収集または共有しますか？」→ **いいえ**
- 端末内で完結する処理（外部に送信しないもの）は「収集」に当たりません。
- セキュリティ（暗号化・削除リクエスト）の設問は、収集なしのため該当なし。

### コンテンツのレーティング（IARC アンケート）

- カテゴリ：ゲーム
- 暴力・恐怖・性的表現・言葉・規制薬物・ギャンブル：すべて「いいえ」
- ユーザー間のやり取り・位置情報の共有・デジタル商品の購入：すべて「いいえ」
- 想定結果：**全年齢（IARC 3+ / ESRB Everyone / CERO 相当なし）**

### ターゲット ユーザーとコンテンツ

- 対象年齢層：13歳以上を選ぶのが手続き上いちばん簡単です。
- 子ども（13歳未満）も対象に含める場合は「ファミリー」ポリシーの審査が加わります。広告・データ収集がないので満たせる見込みですが、手続きが増えます。

### 広告

- 「アプリに広告が含まれていますか？」→ **いいえ**

### アクセス権限

- 申告が必要な権限：なし

## 提出前にそろえるもの

| 項目 | 状態 |
| --- | --- |
| プライバシーポリシーの公開URL | `store/privacy-policy.html` の開発者名・連絡先を埋めて公開する |
| サポートURL（App Store） | GitHub のページや簡単な問い合わせページ |
| 開発者名・連絡先メール | 未定（ストアで公開されます） |
| スクリーンショット | `store/screenshots/`（iPhone 1290×2796、Android 1080×1920、日英各6枚） |
| Play のフィーチャーグラフィック | `store/feature-graphic-{ja,en}.png`（1024×500） |
| アプリアイコン | iOS は AppIcon に 1024 を含めて同梱済み、Play 用は `store/icon-512.png` |
| リリース署名 | Android：アップロード鍵と `android/key.properties`。iOS：Apple Developer の証明書 |
